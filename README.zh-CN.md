# TexasReaper

[English](README.md)

以扑克组合判断、节奏和取舍为核心的移动端网页小游戏。

![TexasReaper 封面](docs/cover.png)

**[在线体验](https://onovich.github.io/TexasReaper/)**

## 项目包含什么

- 扑克牌型。
- 移动端优先。
- 节奏与风险取舍。

## 快速开始

克隆仓库后，用任意静态文件服务器提供仓库根目录；例如：

```bash
python -m http.server 8000
```

## 仓库结构

- `docs/` — 项目文档与设计说明。
- `.github` — 自动化与 GitHub Pages 工作流。
- `frontend/` — 仓库组成部分。
- `orogin/` — 仓库组成部分。
